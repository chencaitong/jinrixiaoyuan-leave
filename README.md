# jinrixiaoyuan-leave

一个离线运行的安卓界面学习项目，演示校园主页、资料编辑、请假列表和详情页的实现。仅在本机编辑和保存示例内容，不连接学校系统，不进行真实请假或审核。

## 功能

- “今日”页的“在校生”图标进入请假示例列表。
- 个人主页、头像、背景、资料和菜单可编辑。
- 请假示例可新增、复制和删除，可修改时间、事由和流程节点。
- 内容仅保存在本机，支持手动导入和导出 JSON 备份。
- “外观与备份”提供匿名化本机内容和使用声明入口。

从旧版本升级时，首次加载会将旧资料、头像、事由和审核人等重置为演示内容；这是本版本的隐私清理行为。以后自行填写的内容仍会保存在本机，需要分享时请先匿名化并检查。

## 安装与使用

支持 Android 8.0 及以上。安装包位于本仓库的 Releases（如有发布）。安装后点击“编辑内容”进入编辑器；菜单和状态均为本机演示内容，不具备真实审批效力。

## 从源码构建

当前构建脚本面向 Windows / PowerShell 7，需要 JDK 21、Android SDK Platform 35、Build-Tools 35、Node.js 和 Python 3。

```powershell
$env:JAVA_HOME = '你的 JDK 目录'
$env:ANDROID_HOME = '你的 Android SDK 目录'
pwsh -File scripts/build.ps1
```

也可以通过 `-JdkPath`、`-BuildToolsPath`、`-PlatformPath`、`-PythonPath`、`-NodePath` 和 `-OutputApk` 指定工具及输出位置。默认 APK 位于 `artifacts/`。

构建脚本默认在被 Git 忽略的 `.local/signing/` 中创建本地签名。请妥善保管密钥；不同签名的 APK 无法直接覆盖已有安装。源码仓库不含发布签名密钥及密码。

运行隐私测试：

```shell
node --test tests/privacy.test.cjs
```

## 隐私与审查范围

应用不申请网络权限、通讯录、定位、短信或外部存储的广泛访问权限。图片和备份文件通过系统选择器由使用者主动选择。禁止 WebView 外部导航，备份按固定字段校验，错误日志不记录输入文本。

**仍需注意：** 本机存储和导出的 JSON 备份不是加密保险箱；手动导出、打印或分享屏幕时，可能公开自己后来填写的信息。匿名化功能不能保证识别任意自由文本里的全部个人信息。请阅读 [隐私说明](PRIVACY.md) 和 [安全审查记录](SECURITY_REVIEW.md)。
